# TARAE Wiki (`taraegame.wiki`)

Independent English community wiki for **TARAE: The Unbound**, developed by **Boundary** and published by **KRAFTON, Inc.** (Steam App ID `4604540`).

## 1. SEO Keyword Architecture & URL Map

| URL Route | Primary Target Keywords | Search Intent & Features |
| :--- | :--- | :--- |
| `/` | `tarae`, `tarae game`, `tarae the unbound`, `tarae wiki` | Game overview, release status, six Seekers and `VideoGame` structured data |
| `/release-date` | `tarae release date`, `tarae demo`, `tarae price` | Announced year and current store status, event demo timeline and pricing status |
| `/classes` | `tarae classes`, `tarae seekers`, `tarae warfiend`, `tarae tiger hunter` | Six Seeker profiles and the official gameplay preview |
| `/platforms` | `tarae platforms`, `tarae steam`, `tarae ps5`, `tarae xbox`, `tarae co-op` | Announced platforms, official listings and online co-op status |
| `/system-requirements` | `tarae system requirements`, `tarae pc specs` | Minimum and recommended PC requirements status from Steam |
| `/faq` | `what is tarae game`, `tarae vs diablo 4`, `tarae taegwido lore` | Searchable & filterable FAQ database with `FAQPage` structured data |
| `/sitemap.xml` | Dynamic XML Sitemap | Auto-generated for Google Search Console |
| `/robots.txt` | Crawler directives | Points search engines to `https://taraegame.wiki/sitemap.xml` |

## 2. Local Development & Production Build

```bash
# Install dependencies
npm install

# Run local development server (http://localhost:3000)
npm run dev

# Build for production
npm run build
```
